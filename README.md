# Controle de Estoque

Aplicação simples em Blazor para cadastrar insumos e categorias, controlar quantidades e registrar movimentações de estoque.

Insumos novos começam com quantidade zero. Ajuste o saldo em **Estoque Total** ou registre entradas e saídas em **Movimentações de estoque**.

O dashboard inclui uma interface de previsão do tempo para Londrina, PR. Os dados meteorológicos não estão habilitados.

## Executar

Requer o SDK do .NET 8. Na pasta do projeto, execute:

```bash
dotnet run
```

Os itens são mantidos em memória durante a execução e não são salvos após reiniciar a aplicação.
