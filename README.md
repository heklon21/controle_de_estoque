# Controle de Estoque

Aplicação simples em Blazor para cadastrar insumos, informar valor unitário e quantidade e acompanhar o saldo total do estoque.

## Executar

Requer o SDK do .NET 8. Na pasta do projeto, execute:

```bash
dotnet run
```

Os itens são mantidos em memória durante a execução e não são salvos após reiniciar a aplicação.
